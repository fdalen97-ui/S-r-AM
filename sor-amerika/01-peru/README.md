# Peru

## Hvorfor Peru

- Lima er en av verdens fremste matbyer (Maido #1 world 50 best 2024)
- Cusco / Sacred Valley / Machu Picchu — kulturell tyngde uten sidestykke
- Peruansk kaffe — premium fra Cajamarca, Cusco-regionen, Chanchamayo
- Pisco, ceviche, anticuchos, ají amarillo, cuy

## Stopp i prioritert rekkefølge

### 1. Lima (3–4 dager)

| Distrikt        | Hvorfor                                       |
|-----------------|-----------------------------------------------|
| Miraflores      | Trygg, hotell-base, Pacífico-kysten           |
| Barranco        | Kunst, kafé-scene, kveldsliv                  |
| Centro Histórico | Plaza de Armas, katedralen, San Francisco-kloster |
| San Isidro      | Forretning, men også Huaca Pucllana           |

**Restauranter** (book 2–3 mnd i forveien for tasting-meny):
- **Maido** — Mitsuharu Tsumura, nikkei-mat, #1 world 2024
- **Central** — Virgilio Martínez, høyde-konsept
- **Kjolle** — Pía León (kona til Virgilio), grønnsaks-fokusert
- **Mérito** — venezuelansk-peruansk, mer tilgjengelig pris
- **Astrid y Gastón** — Gastón Acurio, klassiker

**Mer hverdagslig**:
- **La Mar** — den beste cevichen i Lima (åpent kun lunsj)
- **Isolina** — taberna i Barranco, klassisk peruansk
- **El Mercado** — Acurio-konsept, sjømatfokus
- **Picantería La Nueva Palomino** (når i Arequipa) — type-eksempel

**Kaffe**:
- **Tostaduría Bisetti** (Barranco) — single-origin Cusco
- **Origen** (Miraflores) — moderne specialty
- **Café Z** (Barranco) — Coffee Lab av Carlos Lock

### 2. Cusco (3 dager — minst 2 for akklimatisering før MP)

3 400 moh — drikk coca-te, rolig første dag.

| Sted                 | Hva                                      |
|----------------------|------------------------------------------|
| Plaza de Armas       | Hjertet, katedralen                      |
| San Pedro Market     | Mat, ceviche fra disk, frukter           |
| Sacsayhuamán         | Inka-festning, 30 min over byen          |
| San Blas             | Kunstdistriktet, brattest opp            |
| Qorikancha           | Soltempelet under Santo Domingo          |

**Hotell**: Palacio del Inka (lyx), Antigua Casona San Blas (mid-end), Tierra Viva (verdt for pengene).

**Mat**:
- **Cicciolina** — international, alltid bra
- **MAP Café** — i museet, vakkert
- **Limo** — sushi+ceviche-fusion
- **Pachapapa** (San Blas) — cuy og pachamanca

### 3. Sacred Valley (2–3 dager)

Pisac → Maras → Moray → Ollantaytambo

- **Pisac**: marked + ruiner ovenfor
- **Maras**: salt-bassengene (3 000+ små bassenger)
- **Moray**: konsentriske terrasser, Inka-laboratorium
- **Ollantaytambo**: best bevart Inka-by, nattetog til MP herfra

**Hotell**: Sol y Luna (lyx), Tunupa Lodge (mid).

### 4. Machu Picchu (1–2 dager)

- Tog Ollantaytambo → Aguas Calientes (PeruRail Vistadome eller Belmond Hiram Bingham)
- Buss opp eller vandre (1.5t bratt)
- Bestill billetter 3+ mnd i forveien — ulike sirkler/sirkulasjoner siden 2024-reformer
- Huayna Picchu eller Machu Picchu Mountain — ekstra billett, vandring opp
- Overnatt Aguas Calientes (vanligst) eller Belmond Sanctuary Lodge ved selve ruinen

### 5. Arequipa (2–3 dager) — anbefales hvis 8+ uker

"Den hvite byen" — kolonialvulkansten.

- **Santa Catalina-klosteret** — by i byen
- **Picantería La Nueva Palomino** — UNESCO-listet matkultur
- **Colca Canyon-detour** (2 dager) — kondorer, varme kilder

### 6. Lake Titicaca / Puno (1–2 dager) — kun hvis 8+ uker

- **Uros flytende øyer** (turistfellelignende men interessant)
- **Taquile-øya** — overnatt i lokal homestay
- Høyde 3 800 moh — etter Cusco bør det være OK

## Logistikk

| Strekning           | Måte             | Tid     |
|---------------------|------------------|---------|
| Lima → Cusco        | Fly (LATAM/Sky)  | 1.5t    |
| Cusco → Sacred V.   | Privat / kollektiv | 1–2t  |
| Ollantaytambo → MP  | PeruRail-tog     | 1.5–2t  |
| Cusco → Arequipa    | Fly eller buss   | 1t / 10t |
| Arequipa → Puno     | Buss (PeruHop)   | 6t      |
