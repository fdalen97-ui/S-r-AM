## Apper å installere

- **Google Translate** (last ned spansk + portugisisk offline)
- **Google Maps** (last ned offline-kart per region)
- **Maps.me** — backup
- **Uber / Cabify / DiDi** — taxi i store byer
- **Rappi / iFood** — mat­levering (Sør-Amerikas DoorDash)
- **WhatsApp** — primær kommunikasjon med hoteller/operatører
- **XE Currency** — valutakonvertering
- **Splitwise** — del kostnader hvis dere reiser med andre
- **Polarsteps** — automatisk reisedagbok via GPS
- **All Trails** — vandring (særlig Patagonia)
