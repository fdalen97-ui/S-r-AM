# Bookinger

Mappe for å holde bekreftelser og kvitteringer organisert.

## Foreslått struktur

```
05-bookinger/
├── fly/                    # boarding pass, billettnummer
├── hotell/                 # bekreftelser per destinasjon
├── restauranter/           # tasting-meny-bekreftelser
├── vingaarder/             # lunch-reservasjoner
├── aktiviteter/            # MP, Patagonia-vandring, vinturer
└── forsikring-helse/       # poliser, vaksinasjonsbevis
```

## Kritisk å booke i forveien (i prioritert rekkefølge)

| Tid før | Hva                                          | Hvor                          |
|---------|-----------------------------------------------|-------------------------------|
| 6+ mnd  | Internasjonal flybillett                     | Kayak / Skyscanner / direkte  |
| 4–6 mnd | Machu Picchu inngangsbillett                 | tuboleto.cultura.pe (offisiell) |
| 4–6 mnd | Maido / Central / Kjolle (Lima)              | direkte via web              |
| 4 mnd   | El Chato / Leo (Bogotá hvis aktuelt)         | direkte via web              |
| 3 mnd   | Don Julio / Tegui (BA)                       | hyttegate / OpenTable / direkte |
| 3 mnd   | Lapostolle Residence (Colchagua)             | direkte                      |
| 2–3 mnd | Internflyvninger                             | LATAM / Aerolíneas            |
| 2 mnd   | Hoteller                                     | Booking.com / direkte (cancel-buffer) |
| 1–2 mnd | Vingårder Mendoza (Catena Adrianna m.fl.)    | direkte e-post               |
| 1 mnd   | Patagonia-vandringer (Fitz Roy guide hvis behov) | lokale operatører         |
| 2 uker  | Aktiviteter (dagsturer, vinturer)            | GetYourGuide / Tours by Locals |

## Maler for kommunikasjon

### Vingårdsbooking — engelsk

> Subject: Wine tour & lunch reservation request — [date]
>
> Hello,
>
> We are a couple from Norway visiting Mendoza from [date] to [date]. We would like to book a wine tasting and lunch at [winery name] on [date], for 2 persons.
>
> Could you please let us know about availability, the cost per person, and how to confirm? We are particularly interested in your premium tasting if available.
>
> Thank you,
> [Name]

### Restaurantbooking — spansk

> Asunto: Reserva para 2 personas — [fecha]
>
> Hola,
>
> Quisiera hacer una reserva para 2 personas el [fecha] a las [hora] horas. Es mi primera vez en su restaurante. Si tienen menú degustación, me interesaría mucho.
>
> Muchas gracias,
> [Nombre]

## Bekreftelse-sjekkliste før avreise

- [ ] Pass gyldig i 6+ mnd etter retur
- [ ] Visum sjekket per land (Norge: visum-fritt for alle disse i 2026)
- [ ] Internasjonal billett i innboks + lagret offline
- [ ] Internflyvninger booket
- [ ] MP-billetter booket og bekreftelse i innboks
- [ ] Topp-restauranter booket
- [ ] Hovedhoteller booket
- [ ] Vaksinasjoner: gult feber (kreves Iguazu/Brasil-jungel), tetanus oppdatert, malaria-tabletter hvis Amazon
- [ ] Reiseforsikring — sjekk lengde-grense
- [ ] Ekstra betalingskort
- [ ] Kopi av pass i sky + papir
- [ ] Mobil-abonnement: roaming-pakke eller eSIM (Airalo, Holafly)
- [ ] Adapter (Sør-Amerika bruker ulike standarder per land)
- [ ] Begrensede medisiner: høyde-tabletter (Diamox), magemedisin, smertestillende
