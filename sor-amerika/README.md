# Sør-Amerika — reiseplanlegging

Repository for tur til Sør-Amerika med fokus på vin, kaffe, mat og store opplevelser.

## Kjerne­destinasjoner

| Land      | Hvorfor                                           | Tid   |
|-----------|---------------------------------------------------|-------|
| Peru      | Lima-mat, Cusco, Sacred Valley, Machu Picchu      | 7–10d |
| Chile     | Santiago, Colchagua, Maipo, Casablanca (vin)      | 5–8d  |
| Argentina | Mendoza (Malbec), Buenos Aires, Patagonia         | 10–14d|

**Colombia** ligger som valgfri utvidelse i `07-utvidelser/`. Det er en virkelig god kaffe- og matdestinasjon, men ligger geografisk langt unna kjerneruten og fortjener en egen tur.

## Anbefalt rute (8 uker)

Lima → Cusco → Sacred Valley → Machu Picchu → Arequipa → (fly) → Santiago → Colchagua → Mendoza → Buenos Aires → Bariloche → El Calafate → El Chaltén → BA → hjem

Detaljer i `00-planlegging/rute.md`.

## Beste reisetid

**Skjæringspunktet** for å treffe alt: **slutten av september → starten av desember**.

- Peru: tørrsesong (mai–oktober), best for Machu Picchu
- Mendoza: vår eller høst (mars–april er vendimia/vinhøst, men dyrere)
- Patagonia: åpent november–mars

Detaljer i `00-planlegging/sesong.md` og `00-planlegging/flyvninger.md`.
