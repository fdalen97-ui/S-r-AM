# Alternative ruter — utover kjerne-Peru-Chile-Argentina

Med 12 land og 18 mill km², kan dere strukturere en Sør-Amerika-tur på flere måter. Disse er strukturert etter tema og logistisk sammenheng — geografisk smart sekvens, ikke bare "land-shopping".

## 1. ANDES-ruten — fra Karibia til Patagonia (10–14 uker)

Følg Andes-fjellkjeden fra nord til sør. Den fysisk og kulturelt mest sammenhengende ruten i Sør-Amerika.

```
Cartagena → Eje Cafetero → Bogotá → Quito → Otavalo →
Cuenca → Lima → Arequipa → Cusco → MP → Puno →
La Paz → Salar de Uyuni → Atacama → Santiago →
Mendoza → Bariloche → El Chaltén → El Calafate
```

**Hva du får**: 
- Komplett kaffe-spekter (Colombia + Peru)
- Komplett vin-spekter (Chile + Argentina)
- Pre-koloniansk arkeologi (Tiwanaku, Cusco, MP)
- Andes-naturen i alle dens variasjoner
- Hverdagskultur i 5 land

**Hva det krever**: 12+ uker, høy kondisjon (mye høyde), god ryggsekk-mentalitet.

**Når**: august–november (treffer alle tørrsesongene). Outbound CTG, retur EZE eller FTE.

## 2. KARIBI-Atlanterhavs-ruten (8–10 uker)

Hold deg i lavlandet og kysten, unngå høyde-utfordringer.

```
Cartagena → Tayrona → Caribiske Colombia → 
fly Bogotá → Salvador → Rio → Iguazu → 
Buenos Aires → Colonia → Montevideo → Punta del Este
```

**Hva du får**: Karibia-strender, afrikansk kultur (Salvador), to verdens-storbyer (Rio + BA), rolig avslutning i Uruguay.

**Hva det krever**: 8–10 uker, varmetoleranse, åpenhet for mer mat-fokus enn natur-fokus.

**Når**: april–juni eller oktober–november (mellom regntider, kjøligere).

## 3. AMAZONAS-ruten (8 uker)

Følg verdens største elveystem. Utfordrende men ekstrem natur.

```
Lima → Iquitos (Amazon) → Cusco/MP → 
Puerto Maldonado → La Paz → Rurrenabaque (Madidi) → 
Manaus → Belém → tilbake
```

**Hva du får**: 3 ulike Amazonas-perspektiver (peruansk, boliviansk, brasiliansk), Inca-arven inkludert.

**Hva det krever**: 8 uker, jungelkomfortabilitet, malariaprofylakse, vannfast utstyr.

**Når**: tørrsesong mai–oktober.

## 4. VIN-ruten (4 uker)

Smal og dyp.

```
Salta → Cafayate → Mendoza → Santiago → 
Casablanca → Maipo → Colchagua → 
Carmelo (Uruguay) → Buenos Aires
```

**Hva du får**: 6 vinregioner, alle store druetypene (Malbec, Carmenère, Tannat, Torrontés, Cabernet, Sauvignon Blanc).

**Hva det krever**: 4 uker, vintoleranse, rolig tempo.

**Når**: februar–april (vendimia/vinhøst-sesong i Mendoza og Casablanca).

Detaljer i `08-visualiseringer/tematiske-ruter.html`.

## 5. KAFFE-ruten (4 uker)

Stort sett Colombia-fokusert, fordi det er der dypden ligger.

```
Cartagena → Salento (Eje Cafetero) → 
Manizales → Bogotá → Lima → Cusco → 
Sul de Minas (Brasil) → São Paulo
```

**Hva du får**: UNESCO-listet kaffeland, finca-overnatting, premium peruansk specialty, brasiliansk volum-produsent, world-class brewing-by.

**Hva det krever**: 4 uker, kaffe-genuin interesse (3 av 4 stops er bare for kaffeen).

**Når**: dec–mars (Colombia tørrsesong + Brasil avlings­tid).

## 6. MAT-ruten (4 uker)

Verdens beste restauranter samlet.

```
Bogotá → Lima → Cusco → Santiago → 
Buenos Aires → São Paulo → Rio
```

**Hva du får**: 7 av Latin Americas 50 Best, world-class tasting-menyer.

**Hva det krever**: 4 uker, rikdom, rein-mat-genuin interesse.

**Når**: mars–mai eller september–november (skuldersesong, lettere booking).

Detaljer i `08-visualiseringer/tematiske-ruter.html`.

## 7. NATUR-ruten (10 uker)

For naturalfokuserte.

```
Galápagos (Ecuador) → Amazonas Peru → 
Cusco/Sacred Valley → Salar de Uyuni → 
Atacama → Patagonia chilensk (Torres del Paine) → 
El Chaltén → El Calafate → Iguazu → Pantanal (Brasil)
```

**Hva du får**: Galápagos, Amazon, høyfjell, ørken, isbreer, foss­system, jaguar-spotting.

**Hva det krever**: 10 uker, godt fysisk form, god kald- og varm-utrustning, høy reise­forsikring.

**Når**: juli–september (Galápagos klar, Amazon tørt, Patagonia åpent + tørt).

## 8. SØR-Amerikas Sjelden-besøkt-ruten (8 uker)

For dere som har vært før eller vil stikke fra mainstream.

```
Cartagena → Ciudad Perdida-vandring → 
Santa Marta → grenseovergang Venezuela (skip)? → 
Boa Vista → Roraima-fjellet vandring → 
Manaus → Amazonas → Belém → 
Lençóis Maranhenses → Salvador → Cabo Polonio (Uruguay)
```

**Hva du får**: minimal turist­tetthet, dypeste lokal-opplevelse, Roraima er en av verdens mest fotogene fjell.

**Hva det krever**: 8 uker, tropisk varmtoleranse, ryggsekk-mentalitet, tålmodighet.

**Når**: juli–september.

## 9. GALÁPAGOS-Patagonia-ekspedisjonen (6 uker)

To av kontinentets ekstremiteter, samlet.

```
Quito (3) → Galápagos cruise (8) → 
Lima (3) → Cusco/MP (5) → 
Buenos Aires (3) → Bariloche (3) → 
El Chaltén (5) → El Calafate (3) → Torres del Paine (5) → Punta Arenas (1)
```

**Hva du får**: Galápagos + Inca + Patagonia samlet — kontinentets tre største natur­opplevelser i én tur.

**Hva det krever**: 6 uker, dyrt (Galápagos spesielt), god kondisjon for Patagonia-vandringer.

**Når**: oktober–november (treffer alle tre).

## 10. SØR-Amerika med små barn (6 uker)

For familier.

```
Lima (4) → Cusco akklimatisering rolig (4) → 
Sacred Valley (4) → MP (1) → Santiago (3) → 
Uco Valley vingård-overnatting (3) → 
Bariloche / Lake District (5) → 
Buenos Aires (4) → Colonia (2) → Punta del Este strand (5)
```

**Hva du får**: lavere høyde (Bariloche < Calafate, MP < Cusco), strand i slutten, mindre forflytting per uke.

**Hva det krever**: 6 uker, akseptere tregere tempo, dra i lavsesong (mar–mai eller sep–nov).

## Kjerne­anbefaling — for dere

Basert på tidligere samtale (vin + kaffe + mat fokus, men ikke veldig krevende):

**Hybrid 8 uker — mat/vin/kaffe-balansert**:

```
Lima (4) → Cusco/Sacred V./MP (6) → Santiago (3) → 
Colchagua (3) → Mendoza (6) → Buenos Aires (5) → 
Bariloche (3) → El Chaltén (4) → El Calafate (3) → 
Iguazu (3) → Buenos Aires hjem (1)
```

Dette gir:
- 6 dager Mendoza for vin
- 4 dager Lima + Cusco-restauranter
- Patagonia for natur-balanse
- Iguazu for ikonisk avslutning

Med 1–2 ukers utvidelse: legg til Bolivia (Salar) eller Colombia (Eje Cafetero) avhengig av om kaffe eller dramatisk natur veier tyngst.

Detaljert plan i `00-planlegging/rute.md` (Variant B).
