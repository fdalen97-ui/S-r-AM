# Master sjekkliste — fra planleggning til hjemkomst

Bruk dette som fortløpende dokument. Avhuk når dere er ferdige.

## 9–12 mnd før

- [ ] Beslutt **lengde**: 4 / 8 / 12 uker
- [ ] Beslutt **datovindu**: oktober–desember 2026 vs. mars–april 2027
- [ ] Beslutt **rute**: Variant A / B / C fra `00-planlegging/rute.md`
- [ ] Søk billetter — bruk Google Flights "Date grid" og "Track price"
- [ ] Sjekk **pass-gyldighet** (6+ mnd etter retur)
- [ ] Sjekk **visum-krav** per land (Norge er visum-fritt for alle disse i 2026, men sjekk)
- [ ] Sett opp tur-budsjett, separat sparekonto

## 6 mnd før

- [ ] Bok **internasjonal flybillett** (ofte billigst nå)
- [ ] **Machu Picchu inngang** via tuboleto.cultura.pe — Sirkel 2 + Huayna Picchu er klassikeren
- [ ] **PeruRail Ollantaytambo–Aguas Calientes** tog
- [ ] Reserve på **Maido / Central / Kjolle** i Lima (3 mnd-vinduet åpner)
- [ ] Reserve **Boragó** i Santiago
- [ ] Reserve **A Casa do Porco** São Paulo (hvis Brasil)
- [ ] Reserve **El Chato** Bogotá (hvis Colombia)
- [ ] Vurder **Camino Inca** alt. til tog (separat operatør, fyller seg fort)
- [ ] Begynn **Duolingo spansk** — minimum 30 min/dag

## 4 mnd før

- [ ] Bok **interne flyvninger** (Cusco-Lima-Santiago osv.)
- [ ] Bok **hovedhoteller** — i hver by, gjerne med fri kansellering
- [ ] Bok **Mendoza-vingårder Tier 1**: Catena Adrianna lunch, Zuccardi Piedra Infinita
- [ ] Bok **Lapostolle Residence** Colchagua
- [ ] Bok **Cavas Wine Lodge** Mendoza (1–2 netter)
- [ ] Reserve **Don Julio** og **Tegui** i Buenos Aires
- [ ] **Reiseforsikring** — sjekk lengde-grense, kjøp utvidet om nødvendig
- [ ] **Vaksinasjons­konsultasjon** i god tid:
  - Gult feber (kreves Iguazu, Brasil-jungel, Bolivia)
  - Tetanus oppdatert
  - Hepatitt A/B
  - Tyfoidfeber (vurder)
  - Ev. malaria-tabletter (kun Amazon-jungel)
  - Få internasjonalt vaksinasjons­kort

## 3 mnd før

- [ ] Bok **Patagonia-hotell** og buss-billetter Calafate–Chaltén
- [ ] Reserve **Mendoza Tier 2** vingårder
- [ ] Reserve **closed-door**-restauranter (Casa Felix, Mishiguene)
- [ ] Sjekk **eSIM**-leverandører — Holafly, Airalo
- [ ] Begynn på **pakkeliste** og kjøp manglende ut­styr
- [ ] **Diamox-resept** fra lege (høyde-medisin)
- [ ] Privat sjåfør Mendoza — bok via hotell eller direkte (Trout & Wine, Ampora)

## 2 mnd før

- [ ] Reserve **Mendoza Tier 3** og resterende
- [ ] Reserve **MIL** (Virgilio Martínez Moray) hvis Cusco
- [ ] Sjekk **kreditt­kort** — gi banken beskjed om reisen, ha minst to ulike utstedere (Visa + MC)
- [ ] **Ta ut USD i kontanter** — for Argentina-veksling og buffer
- [ ] **Helse­sjekk**: tannlege, øyenlege hvis briller (kjøp ekstra)
- [ ] Last opp **kopi av pass** til iCloud/Google Drive

## 1 mnd før

- [ ] Reserve **siste-minute** ting: vandring­guide Patagonia, dagsturer
- [ ] Last ned **offline-kart** Google Maps + Maps.me
- [ ] Last ned **offline-språkpakker** Google Translate (spansk + portugisisk)
- [ ] Sjekk **adapter-typer** per land og kjøp universal
- [ ] Lag **dokumentmappe** (digital + papir): pass-kopi, billetter, hotell-bekreftelser, forsikring
- [ ] Sett opp **delt dokument** (Notion/Google Docs) for praktiske ting underveis
- [ ] Lag **WhatsApp-gruppe** for hjemmefronten

## 2 uker før

- [ ] Begynn **pakking** — testpakk og vekt-sjekk
- [ ] **Klipp hår** før reisen
- [ ] **Apotek**: medisin­pakke (smerte, mage, halsbrygg, søvn, plaster)
- [ ] **Bank**: aktiver bruk i utlandet, sett opp varsler
- [ ] **Oppdater Vipps og BankID** for utlandet
- [ ] Sjekk **været** for første destinasjon

## 1 uke før

- [ ] **Sjekk Argentina dollar­kurs**: dolarhoy.com
- [ ] **Sjekk politisk situasjon** og sikkerhetsråd: regjeringen.no/UD
- [ ] **Print** alle bekreftelser i et lite hefte (backup hvis mobil dør)
- [ ] **Hjem**: post-stopp / nabo, planter, dyr, varsler
- [ ] **Ferdig pakkliste** sjekket
- [ ] **Online check-in** når mulig
- [ ] **Powerbank ladet**

## 24 timer før

- [ ] Pakk **håndbagasje** med:
  - Pass + reise­dokumenter
  - Medisiner (alle)
  - Mobil + powerbank + lader
  - 1 sett tøy + undertøy (hvis koffert blir borte)
  - Vannflaske (tom, fyll etter security)
  - Snacks
  - Hode­telefoner, bok / Kindle
- [ ] **Vei** koffert — under 23 kg
- [ ] **Boarding pass** klar, billett-numre tilgjengelig
- [ ] Sjekk **vær** ankomst­by + temperatur

## Mens dere er der

- [ ] Daglig **journal** (5 min før sengen)
- [ ] **Ukentlig backup** av bilder til iCloud/Google Photos
- [ ] **Kvitterings­oversikt** — hold sammen i et hefte eller foto

## Etter retur

- [ ] **Tilbakeblikk-fil** i 06-journal/
- [ ] Bilde­album sortert
- [ ] Vinnotater + noter favoritter
- [ ] Restaurant-rangering for fremtid
- [ ] Anbefalinger for venner
